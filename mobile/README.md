# Venu Mobile

Aplikasi Expo (React Native) untuk penyewa: cari lapangan, pilih jam, pesan, kirim bukti bayar, dan pantau booking.

Cara menjalankan, menghubungkan HP ke backend, dan mode Before/After ada di
[README utama → Menjalankan Mobile](../README.MD#menjalankan-mobile).

```bash
npm install
npx expo start
```
